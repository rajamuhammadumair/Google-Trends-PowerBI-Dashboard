# 🔍 Google Trends Analysis Dashboard

An interactive Power BI dashboard that analyses Google search trends to uncover insights into search popularity, regional interest, and changes in search behaviour over time through dynamic visualisations.

---

## 📌 Project Overview

This project showcases an interactive Power BI dashboard designed to analyse Google Trends data. The dashboard enables users to explore search interest, identify trending topics, compare popularity across locations, and analyse changes in search behaviour through interactive reports.

---

## 🎯 Objectives

- Analyse search interest over time.
- Identify popular and trending topics.
- Compare search popularity across different regions.
- Explore changes in user search behaviour.
- Build an interactive dashboard for search trend analysis.

---

## 📊 Dashboard Features

- Interactive filters and slicers
- Search interest trend analysis
- Regional search analysis
- Topic popularity comparison
- Trend visualisation over time
- KPI cards
- Interactive charts and graphs

---

## 🛠️ Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Data Visualisation
- Business Intelligence (BI)

---

## 📈 Key Insights

- Identify changes in search interest over time.
- Compare the popularity of different search topics.
- Analyse regional differences in search behaviour.
- Discover emerging and declining trends.
- Explore search data through interactive visualisations.
